# GARIK-2.0

Резервная копия пользовательских инструкций и рабочего контекста проекта «Гарик».

## Веб-приложение

- [GARIK OS](index.html) — мобильная личная оболочка с главным экраном, заметками, инструментами и настройками оформления. Встроенные расчётные модули сохранены. Это исходный файл веб-приложения; для публичного запуска нужно включить GitHub Pages в настройках репозитория.

## Содержимое

- [INSTRUCTIONS.md](INSTRUCTIONS.md) — как общаться и помогать.
- [PROFILE.md](PROFILE.md) — устойчивые предпочтения и полезный контекст.
- [CAR.md](CAR.md) — сведения об автомобиле и уже выполненных работах.
- [DEVICE.md](DEVICE.md) — сведения об основном телефоне и настройках.
- [ANDROID/](ANDROID/) — Android-мастерская: Honor X6B, MacroDroid и проверенные эксперименты.
- [PASSAT/](PASSAT/) — цифровая сервисная книжка Passat B5 1.8 ADR: обслуживание, диагностика, ремонты, запчасти и электросхемы.
- [BACKUP_WORKFLOW.md](BACKUP_WORKFLOW.md) — как обновлять резервную копию.
- [CHANGELOG.md](CHANGELOG.md) — история изменений.

## Автоматическая проверка

GitHub Actions проверяет наличие и непустое содержимое основных документов при изменениях в ветке `main`. Это проверка целостности файлов, а не синхронизация с памятью ChatGPT.

## Важно

Этот репозиторий хранит только документы, добавленные сюда вручную или через GitHub API. Он **не** является экспортом внутренней памяти ChatGPT, скрытых системных инструкций, истории чатов, данных аккаунта или голосовых настроек. Не храните здесь пароли, токены, ключи API, VIN и другие секреты.

Репозиторий приватный. Перед добавлением новых личных данных проверяйте, что они действительно нужны.
