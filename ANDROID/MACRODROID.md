# MacroDroid

## Известная информация

- Использовалась версия MacroDroid 1.2026.286.
- Цель экспериментов: простые макросы для быстрого управления телефоном и запуска ChatGPT.
- Tasker не выбирался, поскольку пользователь предпочитает бесплатные решения, если они подходят.

## Результат теста запуска ChatGPT

- Макрос с кнопкой запуска приложения открывал ChatGPT.
- Приложение запускалось в обычном режиме, а не сразу в голосовом разговоре.
- Поэтому этот вариант не считать готовым решением для голосового управления.

## Как добавлять новые макросы

Для каждого макроса записывать:

1. Название и назначение.
2. Триггер.
3. Действия по порядку.
4. Необходимые разрешения.
5. Проверку на Honor X6B.
6. Результат и способ отключения/удаления.

## Безопасность

- Не включать макросы, которые отправляют сообщения, совершают покупки, удаляют данные или меняют важные настройки без отдельного подтверждения.
- Не выдавать MacroDroid доступ к специальным возможностям или уведомлениям без понимания, зачем он нужен.
- Сначала тестировать простые действия, затем усложнять сценарий.
