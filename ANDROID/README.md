# Android-мастерская Гарика

Здесь храним проверенные настройки, инструкции и эксперименты для Android-смартфона.

## Разделы

- [HONOR-X6B.md](HONOR-X6B.md) — устройство, версия системы и известные особенности.
- [MACRODROID.md](MACRODROID.md) — макросы, автоматизация и результаты тестов.
- [EXPERIMENTS.md](EXPERIMENTS.md) — общий журнал настроек и экспериментов с результатами и откатом.

## Правила мастерской

1. Сначала фиксируем модель телефона, версию Android и цель настройки.
2. Проверяем совместимость с Honor и текущей прошивкой.
3. Меняем по одному параметру за раз и проверяем результат.
4. Перед сбросом, удалением данных, выдачей специальных разрешений и изменением системных настроек объясняем риск.
5. Не сохраняем пароли, токены, личные идентификаторы и секреты.
6. Непроверенные идеи помечаем как эксперименты, а не как готовые решения.
