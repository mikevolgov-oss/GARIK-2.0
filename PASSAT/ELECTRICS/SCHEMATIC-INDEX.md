# Указатель электросхем Passat B5 1.8 ADR

Цель: постепенно собрать проверенную библиотеку схем именно для автомобиля с датой производства 16.07.1998 и двигателем ADR.

## Исходные данные
- Passat B5, седан, 1998.
- Дата производства 16.07.1998 (по данным Exist со слов пользователя).
- Двигатель ADR 1.8 / 92 кВт.
- Механическая КПП, код DHZ (со слов пользователя; физически не проверен).
- Не публиковать VIN и личные идентификаторы.

## Важное по периоду выпуска

В опубликованных материалах встречаются пометки `*` для схем до июля 1998 года и `**` для схем с августа 1998 года. Для автомобиля от 16 июля нельзя автоматически выбирать листы только по общей подписи страницы: читать легенду каждого конкретного листа и сверять разъёмы/блоки по фактическому автомобилю. При сомнении нужна заводская документация по дате и комплектации.

## Каталог систем

| Система | Статус | Что нужно собрать |
|---|---|---|
| Управление двигателем ADR / Motronic | Есть справочные ссылки | Полные листы питания, датчиков, исполнительных механизмов и ЭБУ |
| Стартер и генератор | Не собраны | Схема силовых цепей, предохранители, соединения |
| ABS | Частично известна история ремонта массы | Номер блока, разъём, схема питания/массы, точка соединения |
| Наружное освещение | Не собрано | Переключатель, реле, предохранители, разъёмы |
| Аварийная сигнализация и поворотники | Требуется схема | Разъём кнопки, питание, предохранители, связи с центральным замком (если применимо) |
| Вентиляторы охлаждения | Не собрано | Реле, датчики/термовыключатели, ступени |
| Климат/отопитель | Не собрано | Схема по фактически установленной системе |
| Стеклоподъёмники и центральный замок | Не собрано | Схемы дверей и блоков комфорта |
| Приборная панель | Не собрано | Разъёмы, питание, сигнальные цепи |
| Механическая КПП DHZ | Не собрана | Выключатель заднего хода и связанные цепи по фактической комплектации |

## Как пополнять библиотеку

Для каждого листа фиксировать:
- название системы и номер листа;
- модельный год/период применимости;
- код двигателя и КПП, если указаны;
- легенду `*` / `**` и другие сноски;
- номера блоков и разъёмов;
- дату проверки по фактическому автомобилю;
- источник и ссылку.

Не копировать распиновку с другого года или похожего двигателя без проверки. Текущий раздел — указатель, а не полная заводская электросхема и не подтверждённая распиновка всех контактов.
