# Электрика Passat B5 1.8 ADR

Рабочий каталог электросхем, разъёмов, распиновок и точек массы для Passat B5 1998 года с двигателем ADR.

## Данные конкретного автомобиля

- Дата производства: 16.07.1998 (по данным каталога Exist, предоставленным пользователем).
- В опубликованных схемах Passat встречается разделение: `*` — до июля 1998 года, `**` — с августа 1998 года. Для машины, выпущенной 16 июля, в первую очередь проверять листы с отметкой `*`; каждый лист всё равно сверять по его собственной легенде.
- Не переносить автоматически распиновки с автомобилей выпуска с августа 1998 года или с других годов/комплектаций.
- В плане схем Passat с 08/1997 двигатель ADR 1.8/92 кВт указан в координатах 19–26.

## Перед выбором схемы и распиновки

Перед измерением сверять:
- дату производства автомобиля;
- код двигателя ADR;
- механическую/автоматическую коробку;
- комплектацию и PR-коды;
- номер блока управления и маркировку разъёма;
- фактический цвет и сечение провода.

## Важное предупреждение

Этот каталог пока является навигацией и справочником, а не полной заводской электросхемой автомобиля. Не угадывать распиновку по похожему мотору AEB, APT или другому ADR другого года. Не подавать 12 В на контакты ЭБУ и не проверять цепи контрольной лампой без подтверждения методики.

Перед публикацией конкретной распиновки нужно сверить её минимум по схеме соответствующего периода выпуска и маркировке установленного блока. Наличие в схеме обозначения T80 само по себе не подтверждает распиновку каждого контакта конкретного ЭБУ.
