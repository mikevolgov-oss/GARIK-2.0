# Безопасная проверка электрических цепей

## Перед началом
1. Сфотографировать разъём и зафиксировать ориентацию защёлки.
2. Записать номер блока/детали и маркировку разъёма.
3. Сверить схему с датой выпуска и комплектацией.
4. Проверить состояние аккумулятора, предохранителей, массы и разъёмов.

## При измерениях
- Для проверки напряжения использовать мультиметр с высоким входным сопротивлением.
- Не замыкать контакты щупом и не прокалывать изоляцию без необходимости.
- Не подавать внешнее напряжение на сигнальные контакты ЭБУ.
- Не использовать лампу накаливания на выходах ЭБУ и сигнальных цепях датчиков.
- Сопротивление измерять только на обесточенной цепи, предварительно отключив питание и нужные электронные блоки по заводской процедуре.
- Не измерять сопротивление на подключённом и запитанном блоке управления.
- При проверке массы учитывать падение напряжения под нагрузкой, а не только прозвонку.
