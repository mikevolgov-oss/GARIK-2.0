## Данные автомобиля
- Volkswagen Passat B5, седан.
- Год выпуска: 1998.
- Дата производства: 16.07.1998 (по данным каталога Exist, предоставленным пользователем).
- Двигатель: 1.8 ADR, атмосферный.
- Коробка передач: механическая.
- Код коробки: DHZ (сообщён пользователем; маркировка отдельно не проверялась).

## Правила ведения
1. Не записывать предположение как установленную причину.
2. Разделять установленные детали, обсуждавшиеся варианты и неподтверждённые номера.
3. Для подбора проверять VIN/PR-коды, двигатель ADR, дату производства, код коробки и фактическую комплектацию.
4. Новую работу добавлять с датой, симптомом, действиями и результатом.
5. Не добавлять VIN, номера документов и другие чувствительные данные.
