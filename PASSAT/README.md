# Passat B5 1.8 ADR — цифровая сервисная книжка

Основной документ по автомобилю пользователя. Здесь фиксируются подтверждённые ремонты, симптомы, диагностика и детали, которые только обсуждались.

## Данные автомобиля
- Volkswagen Passat B5, седан.
- Год выпуска: 1998.
- Двигатель: 1.8 ADR, атмосферный.

## Разделы
- [Диагностика](DIAGNOSTICS.md) — симптомы, проверки и выводы.
- [История ремонтов](REPAIRS.md) — выполненные работы.
- [Запчасти и подбор](PARTS.md) — установленные и рассматриваемые детали.

## Правила ведения
1. Не записывать предположение как установленную причину.
2. Разделять установленные детали, обсуждавшиеся варианты и неподтверждённые номера.
3. Для подбора проверять VIN/PR-коды, двигатель ADR, год и фактическую комплектацию.
4. Новую работу добавлять с датой, симптомом, действиями и результатом.
5. Не добавлять VIN, номера документов и другие чувствительные данные.
